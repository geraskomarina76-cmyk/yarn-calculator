# Петля — калькулятор пряжи

Одностраничный калькулятор для оценки расхода пряжи по образцу, размерам изделия, выбранному рисунку и метражу мотка.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Как считается расход

Метраж образца делится на его площадь и умножается на общую площадь деталей. Затем применяется коэффициент выбранного рисунка и дополнительный запас. Количество мотков округляется вверх.

Коэффициенты рисунков приблизительные. Для более точной оценки укажите фактический расход образца, связанного тем же рисунком.
